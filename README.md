# 六合彩攪珠機

香港六合彩第五代攪珠機的 3D 網頁模擬器。

## 功能

- **3D 攪珠過程**：49 粒彩球先在入球架排成 5 行，落入球體後由底部氣流攪拌，鏡頭在正面、俯視與弧軌跟拍之間切換。
- **號碼由物理決定**：抽珠時升珠管縮回球底洞口、攪拌逐步減速，第一粒自然滾入洞口的彩球就是攪出號碼，再由升珠管推上弧軌。
- **直接攪珠**：輸入 1–1000 次，不播放動畫，即時列出全部結果。
- **本機統計**：號碼熱度、冷熱號、遺漏期數、連續出現、號碼組合、單雙大小、波色、生肖、尾數、公平性卡方檢定、自選號碼對獎等。
- 撞擊音效、快速模式，支援手機與鍵盤操作。

## 使用

直接以瀏覽器開啟 `index.html`，或透過 GitHub Pages 瀏覽。所有紀錄只存於該瀏覽器（localStorage），不會上傳。

## 技術

- 單一 HTML 檔，無需建置
- [three.js r128](https://threejs.org/)（由 cdnjs 載入）
- 號碼亂數以 `crypto.getRandomValues` 播種；直接攪珠以加密隨機數抽選

## 聲明

本專案為攪珠過程的視覺模擬，與香港賽馬會無關，僅供娛樂與示範，不構成任何投注建議。
